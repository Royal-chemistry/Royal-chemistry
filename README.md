Free, private accounts for small businesses, running entirely in the browser. There's nothing to install and no account to create.

- **Records stay on your device.** There's no server to send them to, and no analytics, trackers or third-party scripts.
- **Upgrades are checked.** Saved data is converted and verified before it's used, and the old copy is kept.
- **Deleting is safe.** Every delete says what else is affected, then offers an 8-second Undo and a Recycle Bin.
- **Tested on every push.** 195 unit tests and 233 browser tests run at desktop and phone sizes, including WCAG AA accessibility checks.
- **Small.** It's under 350 KB to download, with no framework, no build step and no runtime dependencies.

Built with plain HTML, CSS and JavaScript. Tested with Node's test runner, Playwright and axe-core. Hosted on GitHub Pages.
